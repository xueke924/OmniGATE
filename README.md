# OmniGATE

**A Streaming Target Speaker Extraction Front-End for Omni-Modal Interaction**

Ke Xue, Kai Li, Rongfei Fan, and Han Hu

[![Demo Page](https://img.shields.io/badge/Demo-Listen%20%26%20Explore-165DB1?style=for-the-badge)](https://xueke924.github.io/OmniGATE/omnigate-demo/)

## Overview

OmniGATE is a lightweight streaming target speaker extraction front-end
that uses an enrollment utterance to isolate the intended user's speech
for a frozen omni-modal model, supporting target-aware interaction
in multi-speaker environments.

## Release Status

This repository currently provides selected model implementations and
an initial inference script.

We will progressively release the complete source code, the
OmniTAC-Bench dataset, and the full inference and evaluation pipeline,
together with setup instructions.
